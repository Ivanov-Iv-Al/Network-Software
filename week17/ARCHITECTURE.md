# Архитектура финального проекта

## Сервисы

| Сервис | Протокол | База данных | Роль |
|--------|----------|--------------|------|
| API Gateway | REST (HTTP) | Нет | Входная точка для фронта, проверка JWT |
| Task Service | gRPC | PostgreSQL | CRUD задач, бизнес-логика |
| Notification Service | gRPC | Redis (очередь) | Отправка email/telegram уведомлений |
